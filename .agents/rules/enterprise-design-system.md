# Enterprise Production UI Design System

Build UI that looks like a real, enterprise production product (like Stripe, Vercel, or Tesla Telematics) rather than an AI-generated template.

## Rules:
1. **No Artificial Metrics**: Avoid arbitrary statistics, fake percentages (e.g., '99.9%', '10k+ users'), and hollow buzzwords.
2. **Grounded Language**: Use clear, descriptive, and precise language explaining what the software actually does in operational terms.
3. **Restrained Color Palette**:
   - Neutral backgrounds: `#07090e`, `#0c111d`
   - Single functional accent: `#e60012` (crimson red)
   - Border style: `border-white/10`
   - Text hierarchy: `#ffffff` for primary titles, `neutral-300` / `neutral-400` for body, `neutral-500` for metadata.
4. **Realistic, High-Utility Forms**:
   - Every input field must have an explicit business purpose.
   - Strict validation, clear user feedback, and inline error states.
5. **No Vibe-Coded Effects**:
   - Strictly avoid exaggerated glowing borders, gratuitous gradients, particle effects, and heavy neon drop-shadows.
   - Favor clean hairline borders (`border-white/10`), subtle backdrop blurs (`backdrop-blur-md`), and standard, predictable micro-interactions.
